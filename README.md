# homebrew-tap

Homebrew tap for [Simple Simulator Manager](https://github.com/Heckscheibe/SimpleSimulatorManager) and other tools by [@Heckscheibe](https://github.com/Heckscheibe).

## Install

```bash
brew install --cask heckscheibe/tap/simple-simulator-manager
```

Or tap first, then install:

```bash
brew tap heckscheibe/tap
brew install --cask simple-simulator-manager
```

## Update

```bash
brew upgrade --cask simple-simulator-manager
```

## Available casks

| Cask | Description |
| --- | --- |
| `simple-simulator-manager` | Menu bar tool for inspecting and managing apps on Apple simulators |
